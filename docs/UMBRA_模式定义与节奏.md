## 一、记忆片段：**加，而且必须是"世界变了"，不是"发了一张卡片"**

已落地。规则如下：

| 项 | 做法 |
|---|---|
| 载体 | 每关预置 4–5 个**记忆位点**（`def.ms`），落在砖格或地面上 |
| 显形条件 | `shown = min(位点数, save.depth)`，`depth` = 累计通关数（0–5） |
| 显形方式 | 每次进关 0.9 s 淡入，**永久保留**，死亡不清空 |
| 两种痕迹 | 闭眼砖块轮廓（有人成功伪装过）／漂白印（有人在光里动了一下） |
| 不做什么 | **零文字、零 UI、零收集品、零弹窗、零提示音** |
| 结局 | `depth` 不清零 → 世界记得你，你不记得自己 |

### 为什么这样设计

1. **不变成收集清单。** 玩家不用去"拿"记忆，它自己出现在墙上。加了图标就变成任务。
2. **不打断节奏。** 淡入不占操作时间，不暂停、不弹窗。
3. **和 Dead Cells 的叙事语法一致**：你在反复经过同一面墙时，慢慢读懂它。

### 逐步显露的曲线

| 累计通关 | 每关显出 | 玩家读到的 |
|---|---|---|
| 0 | 0 处 | 空的墙，只有自己 |
| 1 | 1 处 | "这里好像有过谁" |
| 2–3 | 2–3 处 | 有成功的，也有失败的 |
| 4–5 | 4–5 处 | "原来一直有人在试" |

**第一局看不到任何记忆**——这是故意的。第二局回来，墙变了，但没有任何数字告诉你"进度 +1"。

### 当前缺口（诚实标注）

`depth` 只在**通关**时 +1。如果玩家反复死在第一关，记忆永远不会显形。下一步应加：每累计 4 次死亡也多显一处（"世界记得你失败过"），这样卡关玩家也能推进理解。P1，本轮未做。

## 二、我们的游戏模式是什么

**一句话：无文字的状态型潜行平台 + 只做结构的轻肉鸽（Rogue-lite，无 Build）。**

### 精确定义

| 维度 | 定义 |
|---|---|
| 玩法内核 | **状态型潜行（State-based Stealth）**——不是"躲到阴影里"（位置问题），是"把自己变成环境"（状态问题） |
| 视角 / 结构 | 2D 横版、单屏高、横向卷轴、每局 5 个房间 |
| 核心动词 | **停止**（伪装）。跑 / 跳 / 冲都是"犯错" |
| 会话结构 | 单局 5 房间；死亡回起点、房间重排 |
| 成长 | **局内零成长**；局外只解锁"理解"（记忆片段），不解锁能力 |
| 失败 | 0.7 s 复活；肉鸽化后回起点 |
| 叙事 | 环境叙事，痕迹跨轮持久化 |
| 平台 | 纯前端浏览器，单页、零依赖 |

### 它不是什么（同样重要）

| 不是 | 原因 |
|---|---|
| 不是 Roguelike | 没有全随机地图、没有永久死亡丢进度、没有 Build |
| 不是平台动作 | 没有战斗、没有 Boss、没有连招 |
| 不是解谜 | 没有开关、没有密码、没有顺序锁 |
| 不是步行模拟 / 叙事冒险 | 有精确的物理与失败判定 |

### 品类坐标

| 参照 | 借什么 | 不借什么 |
|---|---|---|
| Limbo / Inside | 无文字、环境叙事、剪影 | 线性一次通关 |
| Dead Cells | 死亡即循环、世界有记忆、重复探索 | 装备 / 词条 / 数值成长 |
| Sqube Darkness | 黑方块 + 致命光的题材起点 | 躲避式玩法、暗底霓虹 |
| **我们自己的** | **"伪装"这个动词** | — |

一句话区分：**别人卖"躲开光"，我们卖"让光相信你不是活的"。**

## 三、游戏时间是不是太短

**是太短，但"短"不是病，"一次性"才是病。**

### 现状（实测目标值，非推测）

| 指标 | 现在 |
|---|---|
| 单关 | 40–70 s（PRD G3 目标） |
| 单局（5 关） | **3–6 min** |
| 全部内容 | **3–6 min，通关即结束** |
| 死亡 | 0.7 s 原地复活 |

### 判断

3–6 分钟一局，对轻肉鸽其实**不算离谱**（短局 Rogue-lite 常见 5–8 min）。真正的问题是：**一局就等于整个游戏**。玩家没有"再来一轮"的理由，记忆片段也无从累积——所以短被感知成了"空"。

**别把关卡拉长。** 拉长只会往里塞跑图，稀释"忍住不动"的决策密度。正确解法是**把一局变成一轮**。

### 建议数值（[待验证]，本轮未落地）

| 指标 | 现在 | 建议 | 依据 |
|---|---|---|---|
| 单关 / 房间 | 40–70 s | 60–90 s | 容得下"读灯 → 忍住 → 穿过"完整一轮；不靠跑图拖 |
| 房间数 / 局 | 5 | 5–7 | 决策密度 > 时长 |
| 单局 | 3–6 min | **8–12 min** | 轻肉鸽的标准心跳 |
| 总时长 | 一次性 3–6 min | 无限轮；前 3 轮揭示 80% 记忆 | Dead Cells 式"越玩越懂" |
| 死亡成本 | 0.7 s 原地 | 回起点、房间重排、痕迹保留 | 让死亡有结构意义 |

### 反直觉的一点

**记忆片段恰好就是"太短"的解法。** 第一局仍然 3–6 分钟结束，但第二局回来时墙上多了痕迹——时长一秒没变，重玩动机出现了。玩家想再来一轮，不是为了刷分，是为了看这面墙还会变出什么。

所以三件事其实是一件：
> 记忆片段提供重玩动机 → 重玩要求循环结构 → 循环结构把"一局"变成"一轮"，顺手解决了时长。
