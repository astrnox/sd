# UMBRA · 目的、记忆动画与翻转

> v1.0 ｜ 2026-11-14

---

## 零、先纠正一个理解偏差

上一轮我把「记忆片段」做成了**墙上慢慢显出的痕迹**（环境叙事）。你要的是**通关或拿到特定物品时播一段记忆动画**——一段叙事演出，可能是玩家的旧事。

两个都要，但性质不同：环境痕迹是「世界记得你」，记忆动画是**「你开始记得自己」**。后者才是目的的载体。这轮补上。

---

## 一、真正的问题是：没有目的

> 「玩的时候只知道攒星星，到传送门。」

这是整轮迭代里最准的一句诊断。

| | 是什么 | 现在的答案 |
|---|---|---|
| **目标 goal** | 我要完成什么 | 攒 3 个碎片 → 进门 → 下一关 ✅ 有 |
| **目的 purpose** | **我为什么在乎** | ❌ **没有** |

前面七轮我一直在打磨「伪装长什么样」「怎么让玩家看懂」，从没回答「我为什么要伪装、为什么要往前走」。所以玩起来像在替系统打卡。

**光加演出救不了这个。** 演出必须带答案。

---

## 二、目的（定稿）

> **你不是在逃出去。你是在弄清楚：为什么每走进一道门，墙里就多一块闭着眼的砖。**

**答案：那些砖都是上一轮的你。**

门不是出口，是**轮换**：

- 你走进门 → 变成下一局**看守这面墙的光**
- 一个新的你从墙里醒来，什么都不记得
- 所以灯会「愣住」：**它认得你，因为它也曾是你**
- 所以墙里全是闭眼的轮廓：每一个都是走到这里的人

于是所有已有元素一次性有了理由：

| 已有元素 | 之前的读法 | 现在的读法 |
|---|---|---|
| 伪装 | 躲开光 | **变回你本来就是的东西（砖）** |
| 碎片 | 星星 / 收集品 | **上一轮的自己留下的残片** |
| 墙里的闭眼轮廓 | 前人遗迹 | **上一轮的玩家** |
| 灯停顿 3.6 s | 拟人化表演 | **它认出了你** |
| 烧痕 | 失败痕迹 | 有人没忍住，于是又多了一轮 |
| 肉鸽循环 | 为了重玩 | **轮换本身** |

**玩家的目的不是通关，是在某一次循环里弄明白自己在干什么——然后决定还要不要走进那道门。**

## 三、翻转次元：要，但不要做成「另一个维度」

**判断：作为一次性的意义揭示很强；作为新玩法层会毁掉它。**

| 不做 | 做 |
|---|---|
| 平行世界、异次元地图、镜像操作、反转关卡 | **同一个空间，换一个身份重看一遍** |
| 新按钮、新规则、新难度 | 最后一关通关时画面反相；刚才那排砖上方亮起**第二盏灯** |

为什么强：它一次性回答「门通向哪里」，而且不增加一个按键。玩家看到的是——**你出去，就成了那盏灯**；墙里同时多一块砖，那是下一个你。

为什么不能做成可玩的反转关：玩家会读成「关卡变难了」，翻转从**揭示**降级成**机制**，张力全失。

## 四、记忆动画规格（v1.1 可读性修正后）

> **先认错**：v1.0 我写了「零解释、让玩家自己拼五张抽象定格」，还把「不解释」当优点。这是错的。
> **「不解释」≠「看不懂」**。Inside / Limbo 从不让玩家猜谜，它们让玩家**看见因果**。抽象定格是给设计者看的。

### 三条可读性硬标准

| # | 标准 | 落地 |
|---|---|---|
| 1 | 画面里必须有**玩家认得的东西** | **v1.2 修正**：不是整条路线（玩家记不住），是三个他一定记得的**事件** |
| 2 | **一镜因果**，不靠五张图拼 | 淡线作上下文 → 三个事件依次亮起 → 末端长灯照回起点 |
| 3 | 演完**当场兑现**，不留悬念 | 世界替他记（三个痕迹印墙）＋手替他记（伪装速度变化） |

| 项 | 做法 |
|---|---|
| 触发 | 通关时；开场另有一段 2.4 s「轮换」片段 |
| 时长 | 2.4 s，播完才结算 |
| 素材 | `level.events3`：**死过 / 憋最久 / 冲过去** 三个事件；`level.trace` 只作淡背景 |
| 画面 | 淡线 + 三个用游戏内图形画的事件点（漂白印 / 闭眼砖屑 / 冲刺短线）依次亮起；末端白环亮瞳 + 光锥照回起点 |
| 翻转结局 | 同一条轨迹反相重看一遍，灯从末端亮起 |
| 铁律 | 仍然零文字、零 UI、零操作提示——**但因果必须直白** |

### 开场轮换（新增）

点「开始」后先播 2.4 s：**上方一盏灯闭上眼、光散去 → 下方一块砖睁开两只眼**。
目的不在第 5 关才揭示，第一秒就埋下「我上辈子是灯」。只在从标题开始时播，选关直接进，不影响操作。

### 残影 / 记忆 / 开场 三者不冲突

| | 教什么 | 会不会剥夺顿悟 |
|---|---|---|
| 残影（已删） | 教操作 | 会 |
| v1.0 抽象定格（已删） | 什么都不教，也什么都看不懂 | 变成猜谜 |
| v1.1 轨迹回放 | 不教操作，只让玩家认出「那是我刚走过的路」 | 不会 |

## 五、把「攒星星」这件事本身改掉

碎片不再是菱形星星，改成**一块带闭眼缝的砖屑**；HUD 的三个插座、门上的三个插座、结算的三格同步改成方砖。

收集不再是攒分，是**把上一轮的自己收回来**。这一个视觉改动，比任何文案都直接地回答了「我捡这个干嘛」。

## 六、风险与验证

| 风险 | 失败长这样 | 处置 |
|---|---|---|
| 玩家还是不认得那三个点 | 玩后说不出「我死过的地方」 | 让死亡点在下一关真的更难点亮灯，形成手感对照 |
| 灯与路的因果没读到 | 玩后问「门通向哪里」，≥70% 答「下一关」 | 灯出现时加一次朝向起点的明显扫动 |
| 5 次 × 2.4 s 打断节奏 | 玩家开始跳过 | 只在通关播，失败循环不播 |
| 下一关的白线被当成装饰 | 玩家没注意 | 让白线起点正好是玩家本局出生点，形成「我从这儿来」 |
| 翻转被当成 bug | 玩家说「画面反了」 | 反相持续 1.9 s 且渐白收尾 |

**验证方式**：找 3 人玩完 5 关，只问一句「你觉得门通向哪里」。
目标：≥50% 说出「变成灯 / 换了一个自己 / 下一个我」这类话。
不达标不是失败——**只要有人开始问「我是不是上一个」，目的就成立了。**

## 八、下一步（按价值排）

| P | 事项 | 为什么 |
|---|---|---|
| **P0** | **让新灯在下一局真的按上一局玩家的节奏扫** | 把「你成了看守」从结局画面变成真机制——翻转才真正落地 |
| P1 | 拿到墙中碎片时播 0.8 s 短记忆 | 让收集动作当场获得意义，但要不打断 |
| P2 | 死亡累计推进记忆 | 卡关玩家也能读出「世界记得我失败过」 |
| P3 | 随机灯相位 + 房间重排 | 把轮换做成可玩的结构 |

P0 是这套设计最值钱的一步：**玩家第二局遇到的那盏灯，用的是他自己上一局的走法。** 不解释、不提示，但他会隐约觉得这盏灯认得自己。

## 十、v1.2 修正：玩家记不住上一把怎么走的

### 诊断

用户质疑：「玩家能记得住上一把他是怎么走的吗？」——**记不住。**

这是我第二次犯同一类错误：v1.0 把「不解释」当「看不懂」，v1.1 把「系统能记录轨迹」当「玩家能认出轨迹」。
连续位移曲线不属于情景记忆的编码单位。玩家记住的是**事件**：

| 记得住 | 记不住 |
|---|---|
| 我在那道激光下死了三次 | 第 47 帧我在 x=612 |
| 我在那块砖上憋了很久 | 整局走出的那条曲线长什么样 |
| 最后是冲进门的 | 中途每一次微调 |

峰值与结尾最牢（强烈时刻 + 结果），中间过程会被压平成"我走过去了"。所以一条淡白线，对玩家和抽象定格没区别。

### 解法：既然记不住，就别让玩家记

**让世界替他记，让手替他记。**

| 层 | 做法 |
|---|---|
| 只留三个事件 | `death`（最后一次死亡位置）／`hold`（连续伪装最久的位置）／`dash`（最后一次冲刺位置）。缺失时用轨迹中位点补，保证共 3 个 |
| 图形都见过 | 漂白圆印＝烧痕；小方块带闭眼线＝砖屑；短横线＝冲刺拖尾。**不引入任何新符号** |
| 演出 | 淡线只作上下文（α0.22），三个事件在 k=0.24/0.41/0.58 依次亮起，灯在 k>0.72 出现 |
| 世界替他记 | 下一关墙上只印这 3 个点（α0.16），**不再印整条线** |
| 手替他记 | 走到上局憋过的地方 → `press` 底数 0.0003→**0.00008**，伪装更快；走到死过的地方 → **0.0009**，更难冷静。玩家不需要回想，身体先认出来 |

这不是叙事修饰，是**可验证的机制**：`U.memRate` 会随位置变化，测试里有断言。

### 与"目的"的关系

「那些砖都是上一轮的你」不再靠玩家理解一句设定，而是靠第二局的三处手感差异被**感觉到**。
玩家可能说不出为什么，但会觉得「这面墙认得我」——这正是我们要的。

### 下一步修正

之前 P0「让下一盏灯按上一局整条轨迹扫」应改为**按这三个事件点扫**：灯在死亡点停久一点、在憋过的地方扫快一点。轨迹数据保留，但驱动灯的是事件，不是曲线。
