# UMBRA · 叙事与循环方向

> v1.0 ｜ 2026-11-14 ｜ 议题：残影取舍 / Dead Cells 式叙事 / 是否肉鸽

---

## 一、残影：**删掉，不优化**

### 判断

残影再怎么优化都会怪，因为它在三个地方自相矛盾：

| # | 矛盾 | 说明 |
|---|---|---|
| 1 | **它剥夺顿悟** | 无文字游戏的全部快感来自"我自己想明白了"。演一遍给你看，等于替玩家答了题 |
| 2 | **它制造新歧义** | 残影和玩家用同一套几何，玩家会以为那是分身、另一个可操作角色、或幽灵 NPC——刚修好的"读不懂"又被引入 |
| 3 | **它与伪装语义打架** | 伪装的定义是"认不出哪块是我"。可演示结束后却留下一个**明显的人形轮廓**——等于宣布"这里有人藏过"，伪装不成立 |

第 3 条是致命的。**一个教伪装的演示，不能自己暴露伪装。**

### 替代：把「示范」换成「线索」

| | 残影演示（删） | 静态线索（现在） |
|---|---|---|
| 触发 | 第一次被照到 | 第一次被照到（**保留这个目的**） |
| 内容 | 淡入→走→停→看光→压平→淡出，5.1 s | 灯下那块砖慢慢浮出一个闭眼轮廓，0.6 s 淡入 |
| 玩家动作 | 观看 | **推理**："为什么这块砖闭着眼？" → 试着站上去不动 |
| 结果 | 演完留轮廓 | 轮廓本来就是结果，永久留在场景里 |
| 叙事身份 | 一个 NPC 在教你 | **曾经有人活下来**的证据 |

它不告诉玩家怎么做，只证明"这样做有人活过"。这正是下一节要说的叙事方法。

## 二、能不能仿《死亡细胞》的叙事

**能，但要仿的是方法，不是形式。**

Dead Cells 的叙事没有剧情文本、没有过场，靠的是四件事。逐条对照：

| Dead Cells 的做法 | 我们该抄的 | 不该抄的 |
|---|---|---|
| **死亡即循环**：死不是结束，是下一轮的信息 | 烧痕跨轮保留、灯记得你、轮廓留在地图上 | 长篇世界观文本 |
| **世界有记忆，主角没有** | 玩家每轮重置，地图不重置；你越玩越懂这面墙 | 主角身世、对白、过场动画 |
| **环境补 lore**：房间、尸体、涂鸦、物品描述 | 闭眼轮廓、漂白印、灯的 3.6 s 迟疑 | 物品描述文字码 |
| **隐藏区域靠重复探索浮现** | 墙中碎片（必须伪装才拿得到）、活碎片 | 技能树、钥匙门 |

一句话：**Dead Cells 的叙事是"你在反复经过同一个地方时，慢慢读懂它"。** 我们已经在做这件事了——轮廓、烧痕、遗迹全是这个语法，只是还没把它们**跨轮连起来**。

所以答案不是"能不能仿"，是**"我们本来就在这条路上，缺的只是循环"**。

## 三、要不要做肉鸽

**要，但只做「结构肉鸽」，不做「内容肉鸽」。**

### 支持（三条）

1. **现在最浪费的就是这个机制。** "伪装"有极高的重复价值——灯的位置、相位、扫描方向一变，就是一道新题。可我们把它装进 5 关一次性内容里，玩完就结束。
2. **单关 40–70 秒 + 0.7 秒复活**，本来就是肉鸽的心跳节奏，不需要改造。
3. **Dead Cells 式叙事需要循环才能成立。** 烧痕如果只在单关内存在 6 秒，"世界记得你"就只是一句设定；跨轮保留，它才是叙事。

### 反对完整肉鸽（三条，都很硬）

| 风险 | 为什么致命 |
|---|---|
| 装备 / 词条 / Build | 直接违反支柱一"动词只有一个：停止"。玩家开始算数值，就不再"忍住不动" |
| 局内成长（加血、加冲刺、无敌帧） | 把"动一下就死"的压力稀释掉，核心张力归零 |
| 全随机地图 | 纯前端 60 KB、无构建，且手工"安全岛链路"的编排质量会塌 |

### 具体结构

| 层 | 做法 | 理由 |
|---|---|---|
| **房间** | 12–16 个手工房间池，每局抽 5 间组成一条路线 | 保留编排质量，不引入随机地图 |
| **变量** | 灯的相位 / 扫描方向 / 活碎片位置，每局重新随机 | 同一房间每局都是新题，重复价值在这里 |
| **局内** | **零成长**。不加血、不加技能、不拾取强化 | 保护"忍住不动" |
| **局外** | 不解锁能力，只解锁**理解**：每次死亡/通关，揭示一处环境变化（无文字，纯画面） | Dead Cells 式"你越玩越懂" |
| **持久化** | 烧痕与轮廓**跨轮保留在房间上** | 世界记得你，你不记得自己 |
| **失败** | 死亡 → 回到起点，房间重排，但痕迹还在 | 死亡推进理解，不推进数值 |

一句话：**局内零成长，局外只解锁理解。**

这叫"循环是肉鸽的，内容是手工的"——拿到重复可玩性，不引入数值膨胀。

## 四、最小验证切片（建议只先做这一步）

不要一次把上面全实现。先做一个能在 1 天内验证的开关：

| 步骤 | 内容 | 验证什么 |
|---|---|---|
| 1 | 每局开始时，给所有灯一个随机相位种子 | 同一关卡是不是真的变成新题 |
| 2 | 烧痕写入房间数据，跨轮保留（最多 8 处） | 玩家会不会说"这地方我死过" |
| 3 | 死亡后房间顺序重排，HUD 不显示任何"轮次/进度" | 循环能不能不带数字地成立 |

**失败信号**（先定义再动手）：
- 玩家把随机相位读成"运气不好" → 说明变化太大，要收窄随机范围
- 烧痕跨轮累积后画面变脏 → 上限降到 3 处，或只保留最近一轮
- 玩家开始刷"通关次数" → 说明局外解锁做错了，回到纯理解

## 五、与三条支柱的冲突检查

| 新机制 | 支柱一「动词只有停止」 | 支柱二「玩家永远在演」 | 支柱三「世界记得你」 |
|---|---|---|---|
| 随机灯相位 | ✅ 不新增动词 | ✅ 每次都要重新读光 | — |
| 跨轮烧痕 | ✅ | ✅ 死过的地方更难演 | ✅ 核心收益 |
| 房间重排 | ✅ | ✅ | ✅ |
| 局外解锁「理解」 | ✅ 不给能力 | ⚠️ 若做成数值/提示就是破口 | ✅ |
| 装备 / Build | ❌ 直接破坏 | ❌ | — |

只有一处要盯：**局外解锁千万别变成"解锁提示"**，那等于把刚删掉的残影从后门放回来。

---

## 六、结论

1. 残影已删，改成静态线索。演示是施舍，线索才是叙事。
2. Dead Cells 能仿，仿的是"死亡即叙事、世界有记忆"——我们现有的轮廓/烧痕已经在做，缺的是**把它们跨轮连起来**。
3. 肉鸽要做，但只做结构层：手工房间池 + 随机灯相位 + 局内零成长 + 跨轮痕迹。
4. 现在真正的问题不是"要不要做肉鸽"，是**这个机制的重复价值正在被 5 关一次性内容浪费掉**。
