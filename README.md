# UMBRA《暗隙》

> 一款**无文字的 2D 潜行平台**游戏：你是黑暗里的一块黑砖，光是会盯着你的看守。
> 核心只有一个动作——**停住，伪装成墙**。
>
> *A wordless 2D stealth platformer. You are a black cube. Stop moving on a black brick and become part of the wall.*

---

## 快速开始

**双击 `index.html`** 即可在浏览器里玩（零依赖、零构建、零外部请求，`file://` 直接可跑）。

> 若浏览器限制本地文件，可起一个静态服务：`python -m http.server`，再打开 `http://localhost:8000`。

## 操作

| 动作 | 按键 |
|---|---|
| 左右移动 | `←` `→` 或 `A` `D` |
| 跳跃 | `Space` / `W` / `↑` / `J` |
| 冲刺 | `Shift` / `Z` / `K` |
| **伪装** | **站在黑砖上松开方向键，停住不动** |

触屏设备会自动出现虚拟按键。

## 核心机制

- 黑砖上有缝，你能数出格子；靠近黑砖**静止**，身体会压平、对色、闭眼，**正好占满脚下那一格**，跳过全部光照判定。
- 一旦移动，眼睛睁开，光就能照到你；被照满会**烧穿**。
- 光是有意识的看守：你在光里消失，它会**愣住**，然后继续。

## 三个结局

| 结局 | 达成方式 |
|---|---|
| **成为灯** | 集齐碎片，走进门 |
| **成为砖** | 集齐碎片后不进门，伪装着不动 5 秒 |
| **无痕** | 全程不被光看到，走完通关 |

## 技术

- 纯前端：Canvas 2D，固定步长 120 Hz，瓦片 32 px，视口 960×544，DPR ≤ 2。
- 全程序化：图形与音效均由代码生成，**包体内无任何图片/音频文件**。
- 测试：`node tools/smoke-test.js`（85 项断言）。
