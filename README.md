# 查无此人 · NO SUCH PERSON

> 一款**无文字的 2D 潜行游戏**：你是一块黑砖，注视是会读你的光。
> 核心只有一个动作——**停住，从记录里消失**。
>
> **它讲的是一件大多数人看不见的事**：有人活着、劳动、呼吸，却不在任何名册、任何系统、任何人的记忆里。为了让注视无法归档你，你把自己活成了一面墙；代价是，再没人知道这里站过一个人。
>
> *A wordless 2D stealth game about living outside every record. To stay unread, you become the wall. The cost: no one ever knows you were there.*

---

## 快速开始

**双击 `index.html`** 即可在浏览器里玩（零依赖、零构建、零外部请求，`file://` 直接可跑）。

> 若浏览器限制本地文件，可起一个静态服务：`python -m http.server`，再打开 `http://localhost:8000`。

**主玩法**：`▶` = 5 关手工战役（**列名 → 点名 → 空档 → 升格 → 注销**，一条登记的流水线层层递进）；`▦` = 选关。

> **关卡在精不在多**——只有 5 关，每关是"消失"的一个不可替代的阶段（详见 `docs/` 的五关设计说明）。房间池/一局模式已移除。

## 操作

| 动作 | 按键 |
|---|---|
| 左右移动 | `←` `→` 或 `A` `D` |
| 跳跃 | `Space` / `W` / `↑` / `J` |
| 冲刺 | `Shift` / `Z` / `K` |
| **抹除可识别性** | **站在黑砖上松开方向键，停住不动** |

触屏设备会自动出现虚拟按键。

## 核心机制

- 黑砖之间有缝，你能数出格子。靠近黑砖**静止**，身体压平、对色、闭眼，正好占满脚下那一格——你不再是一个"可被识别的对象"，全部光照判定跳过你。
- 一旦移动，眼睛睁开，注视重新锁定你；被照满即**被读完**——一个不在记录里的人，无法承受被归档。
- 注视是有意识的：你在它视野里消失时，它会**愣住 3.6 秒**，然后一切照旧。那是你唯一一次"造成过影响"的证据。
- 第三关里，你消失的那一刻，墙上"上一个也这样消失的人"的闭眼刻痕会亮起。

## 三个结局 —— 三种与记录的关系

| 结局 | 达成方式 | 含义 |
|---|---|---|
| **成为灯** | 集齐三份存档碎片，走进门 | 你终于被登记了——代价是成为**登记别人的人** |
| **成为砖** | 集齐后不进门，在终点伪装静止 5 秒 | 彻底退出可识别性，安全，但不再存在 |
| **无痕** | 全程未被注视照到，走完全程 | 从未进入任何记录——最孤独的一种胜利 |

> 门中央的"眼"会提前告诉你走向哪个结局：睁眼＝将被登记，闭眼一道缝＝从未被记录。

## 技术

- 纯前端：Canvas 2D，固定步长 120 Hz，瓦片 32 px，视口 960×544，DPR ≤ 2。
- 全程序化：图形与音效均由代码生成，**包体内无任何图片/音频文件**。
- 测试：`node tools/smoke-test.js`（120 项断言）；`DIST=1 node tools/smoke-test.js` 测发布产物。
- 发布构建：`node tools/build.js --strip` → `dist/`，raw 约 94.5 KB，满足包体预算。
- 存档：新版键 `nsp.save.v1`，自动迁移旧版《暗隙》存档（`umbra.save.v2`），迁移后删除旧键。

## 入口与调试

- `▶` = 5 关手工战役；`▦` = 选关。
- 生产环境不暴露调试接口；本地开发可用 `?dev=1` 或 `window.__NSP_DEV__=true` 开启（兼容旧开关 `__UMBRA_DEV__`）。内部调试对象仍名 `window.UMBRA`（测试与截图工具依赖），对外品牌名为 NO SUCH PERSON。
